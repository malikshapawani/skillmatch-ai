
# 🎯 SkillMatch AI — Smart CV Analyzer

An interactive Streamlit application that compares a CV
with a job description and identifies relevant skills.

## Features
- PDF CV upload and text extraction
- Technical skill detection
- CV–job similarity score
- Skill coverage analysis
- Missing skill identification
- Interactive dashboard and charts
- Downloadable analysis report

## Technologies
- Python
- Streamlit
- PyMuPDF
- Scikit-learn
- Pandas
- Plotly
- Pytest

## Setup

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies:

   `python -m pip install -r requirements.txt`

4. Run the application:

   `python -m streamlit run app.py`

## Run Tests

`python -m pytest -v`

## Limitations

Similarity scores are text-based indicators and do not
predict hiring outcomes.
